# Customer Segmentation Project

Segmenting customers based on demographics and purchasing behavior using Python and Scikit-Learn.

## Key Features
- **Clustering:** K-Means clustering (`scikit-learn`) with StandardScaler, Elbow Method & Silhouette Score (K = 4)
- **Purchase Pattern Analysis:** Analyzed customer demographics, spending score, purchase frequency, and preferred product categories
- **Visualizations:** PCA 2D Cluster Plot, Annual Income vs Spending Score Scatter Plot, and Category Preference Heatmap
- **Targeted Insights:** Actionable marketing and retention strategies for each customer segment

## Files
- `Welcome_To_Colab.ipynb` — Complete Python code, outputs, charts, and segment summary
- `segmented_customers.csv` — Final customer dataset with assigned cluster labels
